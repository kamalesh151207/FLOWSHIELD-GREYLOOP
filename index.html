● DEMONSTRATION SIMULATION & SCADA ARCHITECTURE

This dashboard interface is operating in Demonstration Simulation Mode for the Smart India Hackathon jury presentation (Problem Statement: SIH26257).

All telemetry values (flow rate, water levels, soil moisture, and water quality benchmarks) are dynamically computed by the prototype simulation service and synchronized with the PostgreSQL cloud data store when available.

Hardware API Interface: The application architecture uses a decoupled data layer (window.SimulationService / window.ApiService) allowing immediate connection with field ESP32 controllers via MQTT / WebSocket.
